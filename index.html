Little_card

一堆自包含的小卡片：每张都是一个单独的 HTML，不依赖框架、不依赖构建。
用的时候丢一个 iframe，靠 ?card= 指定要哪张就行。

怎么用

把这一行贴到你的页面里，card 换成下面任意一张卡片的 id： 


    

      需要 GitHub Pages。仓库设置 → Pages → Source 选 main / root 才有能访问的地址；
      raw.githubusercontent.com 返回的是纯文本，iframe 里会直接显示源码。

      尺寸按每张卡片下面标的给，卡片是按「展开后」的占位设计的。

      透明：卡片检测到自己被 iframe 套着就会去掉 demo 底色，直接贴在你的页面上；也可以显式写 &bg=transparent。
